# P1 — Development Outcomes Analytics

Subnational development-outcomes analytics project covering 2015–2020.

## Scope

- 28 countries
- 513 subnational regions
- 3,078 region-year observations
- Multiple socioeconomic, demographic, spatial and development data sources

## Pipeline

1. Data-source audit
2. Data extraction
3. Harmonization and quality assurance
4. Analytical preparation
5. Robust Mixed Fuzzy C-Medoids (M-Exp-FCMd)
6. Cluster evolution and interpretation
7. Results export and visualization

## Current methodological design

Regions are characterized from their multivariate trajectories over 2015–2020.  
The final clustering method is Robust Mixed Fuzzy C-Medoids (M-Exp-FCMd), with the number of clusters selected using the Fuzzy Silhouette criterion.

Raw data, downloaded rasters, intermediate datasets and local analytical databases are not stored in this repository.
